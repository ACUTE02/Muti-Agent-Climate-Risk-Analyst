## 📖 Overview

**Multi-Agent Climate Risk Analyst** is an end-to-end **agentic GenAI system** built for India's drought-prone Rajasthan region. It answers real questions an agricultural extension officer or farmer-advisory consultant would ask — *"what's the drought risk for Barmer over the next three months, and what does that mean for a wheat crop?"* — with a plain-language report that is:

- **Actually predictive where it claims to be**, and honest about where it isn't
- **Grounded**, meaning every number in the final report is mechanically checked against real tool output and retrieved sources, not just generated by an LLM and trusted
- **Backed by cited, live external data** (IMD, NASA POWER, data.gov.in) — never blended into the system's own measured figures

Six agents work together under a LangGraph orchestrator: a drought-forecasting agent, a heat-stress agent, a RAG retrieval agent, a crop-impact agent, an orchestrator/synthesis agent (Gemini), and a **mechanical, non-LLM grounding-verification layer** that is the project's real differentiator.

## ✨ Features

- 🌧️ **Validated 1-month drought forecast** — a Ridge regression model measuring a skill score of **+0.21 to +0.26** against climatology, replicated across 4 independent historical time windows
- 🌡️ **Heat-stress risk observation** — IMD heat-wave criteria applied to live data (forecasting was tried, honestly measured, and found to carry no skill — see below)
- 🧠 **Agentic orchestration via LangGraph** — a state graph that routes natural-language requests to the right tools using real function calling, not keyword matching
- ✅ **Mechanical grounding checker** — extracts every number an LLM writes and verifies it against actual source data; caught and blocked a real LLM fabrication during testing
- 🏷️ **Per-horizon honesty labels** — `validated` / `weak-directional` / `no skill`, never collapsed into a single confidence dial
- 📚 **RAG retrieval** — ChromaDB + Gemini embeddings over a curated corpus of government/institutional climate documents, precision@5 = 1.0
- 🌾 **Crop-impact assessment** — a hybrid deterministic + LLM agent that only cites sourced yield-impact coefficients, never invents one
- 🛰️ **3 live cited external sources** — IMD, NASA POWER, and data.gov.in, each explicitly attributed, never presented as this project's own result
- 🔌 **FastAPI backend + Docker** — a real API with `/report /health /evaluation /examples /quota` endpoints, containerized for deployment
- 🧪 **360+ automated tests** — covering data-leakage guards, grounding precision/recall, and live-integration paths

## 🏗️ Architecture

```
                         User Query (natural language)
                                    │
                                    ▼
                    ┌───────────────────────────────┐
                    │      LangGraph Orchestrator     │
                    │   (agentic decision layer)      │
                    └───────────────┬─────────────────┘
                                    │  routes via Gemini function calling
              ┌─────────┬──────────┼──────────┬─────────────┐
              ▼         ▼          ▼          ▼             ▼
        ┌─────────┐┌─────────┐┌─────────┐┌──────────┐┌────────────┐
        │ Drought ││  Heat   ││   RAG   ││   Crop    ││  IMD / NASA  │
        │Forecast ││ Stress  ││Retrieval││  Impact   ││POWER/data.gov│
        │ (Ridge) ││(observ.)││(Chroma) ││ (hybrid)  ││ (live-fetch) │
        └────┬────┘└────┬────┘└────┬────┘└─────┬─────┘└──────┬──────┘
             └──────────┴──────────┴───────────┴─────────────┘
                                    │
                                    ▼
                    ┌───────────────────────────────┐
                    │   Synthesis Agent (Gemini)      │
                    │   (generative layer)            │
                    └───────────────┬─────────────────┘
                                    ▼
                    ┌───────────────────────────────┐
                    │  Mechanical Grounding Checker   │
                    │  (no LLM — verifies every       │
                    │   number against source data)   │
                    └───────────────┬─────────────────┘
                                    ▼
                         Final Report (or a flagged
                         "unverified figures" banner)
```

This is deliberately **both** an AI agent system and a GenAI system: LangGraph provides the agentic decision-making (which tools to call, in what order), Gemini provides the generative synthesis (turning tool output into readable prose), and a layer of purely deterministic code underneath — the forecasting models, the risk-dominance logic, and the grounding checker — keeps the generative layer honest.

## 🚀 Local Deployment

```bash
git clone https://github.com/ACUTE02/Muti-Agent-Climate-Risk-Analyst.git
cd Muti-Agent-Climate-Risk-Analyst
pip install -r requirements.txt
python -m scripts.setup            # regenerates everything a fresh clone needs
uvicorn api.app:app --reload --port 8000
```

Then visit `http://localhost:8000/app/` for the query UI, or `http://localhost:8000/docs` for the API. Requires a `GEMINI_API_KEY` (and optionally `DATA_GOV_IN_API_KEY`) in a local `.env` file.

### Docker

```bash
docker build --secret id=gemini_key,env=GEMINI_API_KEY -t climate-risk-analyst .
docker run --rm -p 8000:8000 -e GEMINI_API_KEY=your-key climate-risk-analyst
```
